# Healthcare Accessibility in Ikeja, Lagos State

This repository contains my GeoDev Lab project on healthcare accessibility in Ikeja, Lagos State, Nigeria.

The project focuses on identifying residential areas that are located more than 5 km from the nearest healthcare facility.

## Project Question

Which residential areas in Ikeja, Lagos State are located more than 5 km from the nearest healthcare facility?
